# watch 스킬 답변 형식: 한줄 요약 → 핵심정리 → 내용

날짜: 2026-08-26

## 변경

`skills/watch/SKILL.md` Step 4에 요약 출력 형식을 고정.

1. **한줄 요약** — 영상 정체 + 핵심 한두 문장
2. **핵심정리** — 스캔 가능한 불릿 (수치·비교·결론, 타임스탬프)
3. **내용** — **최대한 자세히**: 프레임+자막 근거로 구간별/연대기 전개, 화면·수치·제품명·트레이드오프까지 보강. 핵심정리의 얇은 바꿔 쓰기로 끝내지 말 것.

전문 질문이면 먼저 직접 답한 뒤, 전체 요약이 함의되면 위 세 절을 이어서 작성.
